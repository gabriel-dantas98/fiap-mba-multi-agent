SDK mcp 1.x · FastMCPTransporte Streamable HTTP

Confere Host/Origin, lê o JSON-RPC, acha a tool pelo nome e valida os argumentos contra o schema gerado das type hints.

TransportSecurity: Host in ["mcp-quantum.gabsdevops.workers.dev", ...]
method "tools/call"  →  ToolManager.call_tool("obter_avaliacao_produto")
arguments {"produto": "console"}  ✓  schema {produto: string}
Host fora da allowlist (DNS rebinding) → 421
argumento inválido / tool inexistente → isError: true
chama a função Python decorada
5
Nosso códigoservidor.py → catalogo.py → dados.py

A tool não sabe nada de HTTP: recebe um str, consulta o catálogo em memória e devolve um dict.

@mcp.tool()                              # src/servidor.py
def obter_avaliacao_produto(produto: str) -> dict:
    encontrado = catalogo.obter(produto)    # 'console' não é ID → None
    if encontrado is None:
        [encontrado] = catalogo.buscar_por_nome(produto)  # → P023
    return catalogo.avaliacao(encontrado)  # lê src/dados.py
produto não encontrado ou nome ambíguo → ValueError vira isError: true com as opções válidas
dict → JSON → mesmo caminho de volta
