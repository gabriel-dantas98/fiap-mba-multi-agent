# Cloud & Cognitive Environments

Entregas da disciplina organizadas por aula.

## Estrutura

```text
cloud-cognitive/
├── aula01/
│   ├── entrega-grupo-aula01.md
│   ├── README.md
│   ├── diagramas/
│   ├── terraform/
│   ├── bicep/
│   ├── scripts/
│   └── evidencias/
└── aula03/
    ├── entrega-grupo-aula03.md
    ├── README.md
```

Cada aula mantém os artefatos necessários para o ZIP do Portal FIAP.
Estados do Terraform, credenciais e chaves privadas nunca devem ser versionados.

Ver [`aula01/README.md`](aula01/README.md) e [`aula03/README.md`](aula03/README.md)
para provisionar, validar e empacotar.

Cloud Agents (Terraform + Azure CLI): ver [`docs/cloud-agent-terraform.md`](../docs/cloud-agent-terraform.md).
